# Large results

Since: v0.1.0

![100,000 rows in the virtual grid](../images/large-results.png)

| Item | Behavior |
|---|---|
| First page | 500 rows. More rows load when you scroll to the end |
| Fetch all | Loads all rows of the result |
| Virtual grid | Only the visible rows are in the page. 100,000 rows scroll smoothly |
| Max. Rows | Status bar field (F7). `0` = no limit |
